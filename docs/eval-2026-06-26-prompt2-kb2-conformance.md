## 5. 残留问题（新 KB 后仍存）

1. **q32 平台卡顿**：两模型仍兜底——检索盲区（KB 里相关 chunk 召回不到），需补 chunk 或加关键词兜底。
2. **q33 成果录入用不了**：v4 兜底、Qwen3 角度偏（答「必填字段」而非 ref 的「角色权限/项目变更/操作入口」）——检索召回的 chunk 不对症。
3. **q2 下载模板 / q30 下载验收证书**：v4 兜底（Qwen3 能给部分）——v4 对这两类检索阈值偏严。
4. **q11 验收/归档附件 / q26-27 待办操作 / q31 成果激励 / q35-36**：两模型都 △——需要更细的 chunk（具体附件清单、4 种待办原因、≥50% 收益分配等专有内容召回靠后）。
5. **q3 十四五规划**：两模型「国家层面」都弱——国家政策文档在 KB 里片段不足。

## 6. 结论

新 KB（更优 chunker）+ 重排减半，**Qwen3 符合率从 53% 升到 68%、与 v4 并列**，且重排 token 砍半（成本下降）。两模型答得更完整、引用规范。剩余提升空间集中在**检索召回**（q32/33 等盲区、q11/26/31 等细粒度内容），属 chunk 覆盖/检索调优，而非 prompt 或模型。**生产可用 v4 或 Qwen3 任一**（68% 符合，互有长短：v4 答得更结构化带表，Qwen3 更稳）。
